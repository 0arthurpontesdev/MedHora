# Firestore analysis - MedHora Família

- Instance: `(default)`, Standard edition, native mode.
- Authentication: Firebase Auth; verified Google email for full accounts; anonymous paired devices are scoped by pairing documents.
- Agenda paths: `users/{uid}/medications/{id}` and `users/{uid}/doses/{doseKey}`.
- Family paths: `members`, `connections`, `dependents`, and `control/access` below each user.
- Reads: owners, explicitly invited members, guardians of managed minors, and paired devices according to the existing helper functions.
- Writes: medication changes are limited to owners and guardians; dose confirmation is limited to owners, guardians, and paired devices.
- Dose schema added in this change: medication identity, scheduled timestamp, actual timestamp, out-of-schedule flag, schedule-adjusted flag, recording UID, and update timestamp.
- Medication schema added in this change: `scheduleAnchorAt`, used only for interval schedules while `startsAt` continues to determine treatment duration.
- Queries reviewed: owner-scoped subcollection snapshots; `where(deviceUid == ...)` for token cleanup; `where(ownerUid == ...)` for invitation cleanup. No new collection-group or cross-owner query was introduced.
- Default-deny catch-all remains in place.
